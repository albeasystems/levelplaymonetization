# levelplaymonetization website

Landing page for the levelplaymonetization iOS app. Vite + React + Tailwind v4.

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # static site in dist/
```

Deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.
Screenshots in `public/shots` are optimized with `npm run shots` from `raw-shots/` (not committed).
