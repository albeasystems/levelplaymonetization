サポート

よくある質問への回答です。解決しない場合は、直接ご連絡ください。

よくある質問

LevelPlay アカウントはどのように接続しますか？

設定を開き、LevelPlay のセクションで、LevelPlay アカウントの Secret Key と Refresh Token を入力し、「接続をテストして保存」を選択します。 接続するまでは、本アプリはデモデータを表示するので、中身を確かめられます。

キーを入力しても安全ですか？

認証情報は iPhone のキーチェーンに、お使いのデバイス内だけに保存されます。当社のサーバーは経由しません。本アプリはお使いのデバイスから直接 LevelPlay と通信します。 設定、接続を解除して認証情報を削除から、いつでも削除できます。iOS ではアプリを削除してもキーチェーンの項目が残ることがあるため、アンインストールの前に行ってください。

接続テストが失敗します。何を確認すればよいですか？

Secret Key と Refresh Token が、先頭や末尾に空白なく最後までコピーされているか、同じ LevelPlay アカウントのものかを確認してください。インターネットに接続されていることも確認してください。 それでも失敗する場合は、本アプリが表示するメッセージを添えてご連絡ください。キーそのものは、決して送らないでください。

数値が LevelPlay のダッシュボードと違うのはなぜですか？

本アプリは、LevelPlay のレポートサービスが返す内容を表示します。違いは、多くの場合、日付範囲やタイムゾーン（このサービスは UTC で報告します）、 または LevelPlay がまだ処理を終えていないデータによるものです。両方で同じ期間を比較してみてください。

どのネットワークと国が表示されますか？

LevelPlay のレポートに含まれるものがすべて表示されます。ネットワークタブでは、収益シェア、eCPM、フィルレート、表示率、インプレッションでランキングされ、 国タブでは、地図とアプリ × 国のマトリクスが表示されます。

アラートはどのように動作しますか？

Pro では、「eCPM が20%下落」のようなルールを作成できます。必要に応じて、特定のアプリ、国、ネットワーク、広告タイプに限定できます。各ルールは、直近7日間をその前の7日間と比較します。 確認が出たら通知を許可し、iOS が許可したときにデータを確認できるよう、Appのバックグラウンド更新をオンにしておいてください。

レポートはどのように書き出しますか？

概要の上部にあるドキュメントアイコンをタップすると、PDF または CSV レポートをプレビューして共有できます。レポートは Pro に含まれます。

Proを購入したのに広告が表示されます。

本アプリを終了してから、もう一度開いてください。それでも広告が表示される場合は、設定を開いて「購入を復元」を選択してください。購入時と同じ Apple ID を使用します。 それでも解決しない場合は、ご連絡ください。

新しいデバイスで Pro を復元するには？

設定を開き、購入に使用した Apple ID でサインインしたまま「購入を復元」を選択します。Pro は追加料金なしで復元されます。

広告のパーソナライズ方法を変更できますか？

はい。トラッキングの許可は、iOS の設定、プライバシーとセキュリティ、トラッキングで変更できます。同意フォームが必要な地域では、設定、プライバシーの選択から再度開けます。 Pro を購入すると、広告は完全に非表示になります。

対応しているデバイスと言語は？

iOS 17 以降の iPhone および iPad（縦向き）。本アプリは、英語、スペイン語、ドイツ語、フランス語、イタリア語、ポルトガル語、アラビア語、ヒンディー語、簡体字中国語、日本語、韓国語、ベトナム語に対応しています。
